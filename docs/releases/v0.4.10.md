# Antigravity Gemini 補上 Argon 額度

- Gemini 卡下方恢復顯示 Gemini 4 Argon 週額度。Argon 只有 `daily-` 主機搭配 agy CLI 的客戶端識別（`antigravity/cli/1.3.6 windows/amd64`）才會回傳，因此改為從 plain 主機取 Gemini 與 Claude/GPT 的數字，再從 `daily-` 主機嫁接 Argon；Argon 請求失敗時保留基礎讀數，不影響卡片。
- Gemini 數字改以 plain 主機為準：實測與 agy `/usage` 畫面一致（週額度 98.22%），`daily-` 主機目前對 Gemini 回的是恆為 1 的值。
- 診斷腳本 `scripts/diagnose-quotas.ps1` 新增各客戶端識別與其他額度 RPC 的比較，輸出仍只含狀態碼、欄位型別與額度數字。

驗證：219 項自動測試通過；以真實帳號的 agy 回應確認 Argon 的來源與數值。Windows 建置與打包由 GitHub Actions 執行。

下載 Windows ZIP 後解壓，執行 Manapoint.exe；launcher.exe 請保留在同一資料夾。已安裝版本可從更新選單升級。
