# 新增 Cursor 訂閱用量

- **Cursor 月用量與重置倒數**：讀取本機 Cursor CLI 或桌面程式登入，查詢訂閱用量；支援多帳號、Auto/API 分池、個人額度與團隊共用池。
- **沿用現有顯示與記錄**：Cursor 可顯示於桌面面板、托盤、用量歷史、iCUE LCD 與 Herdr 狀態列／彈出視窗。
- **登入與錯誤處理**：每次更新重讀登入；登入輪替時重試一次，失效或限流時保留上次成功數字。未提供額度時不假造 0%，憑證不寫入快取、歷史或本機 API。
- **Herdr 獨立模式同步更新**：Windows 發布流程會重建並驗證 `manapoint-cli.exe`，遠端安裝也改用有 SHA-256 校驗的 release 套件，避免沿用舊 collector。

既有使用者請到設定頁勾選 **Cursor**，並先登入 Cursor 桌面程式或執行 `cursor-agent login`。
加密的桌面登入需改用 CLI 檔案登入；本版支援每月訂閱池，尚未整合舊式按次數方案與其他介面的週額度。

驗證：247 項自動測試通過；Chromium 驗證五種主題、兩種排列共 30 種情境，以及設定開關和 iCUE 顯示。Windows 建置、CLI 煙霧測試與打包由 GitHub Actions 執行；尚未使用真實 Cursor 訂閱帳號驗證。

下載 Windows ZIP 後解壓，執行 Manapoint.exe；launcher.exe 請保留在同一資料夾。已安裝版本可從更新選單升級。
