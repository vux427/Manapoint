# Claude Fable 系列每週用量

- **Fable 每週額度**：Claude 卡片新增 Fable 系列的每週用量與重置倒數，與全模型每週總用量分開顯示；支援帶版本的 Fable 名稱。
- **同步顯示與記錄**：精簡主題、用量歷史、趨勢、額度提醒、iCUE 與 Herdr 內嵌版保留 Fable 分組。每週顯示開關同時控制總用量與 Fable。
- **相容未提供 Fable 的帳號**：從 usage 回應的 `limits[]` 讀取模型分項；缺少 Fable 時不假造 0%，畸形或重複的可選項目不影響既有總用量。

驗證：252 項自動測試通過，涵蓋 Fable 分項解析、重置時間、缺失與異常資料、分組顯示、歷史、匯出、趨勢及提醒。Windows 建置、CLI 煙霧測試與打包由 GitHub Actions 執行；尚未使用真實 Claude 帳號驗證。

下載 Windows ZIP 後解壓，執行 Manapoint.exe；launcher.exe 請保留在同一資料夾。已安裝版本可從更新選單升級。
