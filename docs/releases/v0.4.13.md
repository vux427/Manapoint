# 修復 Antigravity Gemini 即時用量更新與支援 Herdr Desktop 內嵌 Mod

- **修復 Antigravity Gemini 用量更新問題**：端點查詢順序調整為優先使用 `daily-` 主機與 agy CLI 客戶端識別（`antigravity/cli/1.3.6 windows/amd64`）。解決先前面向 plain 主機時，Gemini 5 小時滾動額度恆為 0%（flat 1.0）以及週額度與重置時間滯後不準確的問題；現在數值與 `agy /usage` 即時畫面完全一致，並能在單次請求中完整取得 Gemini、Claude/GPT 與 Argon 額度。
- **全新 Herdr Desktop 內嵌用量 Mod (`herdr-mod/`)**：
  - `manapoint-status`：無縫整合進 Herdr 工作區底部狀態列，提供各 AI 提供者官方品牌 SVG 圖示、狀態膠囊、最急迫用量點指示與懸浮明細。
  - `manapoint-popup`：支援點擊狀態列展開彈出式管理面板，包含完整模型卡片、即時重新整理、提供者開關篩選設定。
  - **完整用量歷史紀錄**：遷移並擴充歷史紀錄分頁（📜 歷史），支援 24 小時 / 3 天 / 7 天時間範圍、提供者快速篩選標籤、分頁瀏覽與狀態標籤。
  - 本地 API 新增 `/v1/history` 端點，`manapoint-cli` 新增 `--history` 命令列查詢支援。
- **功能清理**：完全移除消耗速度預測提示（「照目前速度 n day 後用完」），保持介面簡潔清晰。

驗證：224 項自動測試全數通過；`herdr-app check` 通過；以真實帳號與 agy CLI 交叉比對即時數字無誤。Windows 建置與打包由 GitHub Actions 執行。

下載 Windows ZIP 後解壓，執行 Manapoint.exe；launcher.exe 請保留在同一資料夾。已安裝版本可從更新選單升級。
