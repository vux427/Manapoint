# 不安裝 OpenCode 也能監測 Grok 和 Go 額度

- **Grok 支援 Pi 登入**：在 Pi 用 `/login` 登入 xAI 訂閱後，Manapoint 可自動取數，不必啟動 Pi 視窗或安裝 OpenCode。仍相容舊 OpenCode 登入；兩個來源確認為同一 xAI 帳號時只顯示一組額度。
- **OpenCode Go 支援金鑰直連**：可用 `MANAPOINT_OPENCODE_GO_API_KEY` 設定 Go workspace 金鑰，或沿用 `OPENCODE_API_KEY`。設 `MANAPOINT_GO_SOURCE=direct` 可停用舊 OpenCode 路線。
- **卸載前檢查**：原始碼目錄可執行 `node scripts/check-without-opencode.mjs`，以隔離環境確認是否拿得到最新額度，不使用快取、不刪檔，也不續期 Pi 登入。

本機已驗證 Pi 能讀到 Grok 最新週額度，Go 金鑰可直連讀取 5 小時、每週、每月額度。Windows 建置與打包由 GitHub Actions 執行。

下載 Windows ZIP 後解壓，執行 `Manapoint.exe`，並將 `launcher.exe` 留在同一資料夾。既有安裝可從更新選單升級。
