# 右鍵選單支援直接安裝 Herdr 內嵌版

- **右鍵選單新增「安裝 Herdr 內嵌版…」**：在桌面浮動面板或系統托盤右鍵選單中，點擊即可一鍵在背景自動安裝 Herdr 狀態列 Mod、用量彈出視窗與專屬 `manapoint` 佈局，安裝完成後自動發出系統通知並將 Herdr 切換至該佈局。
- **本機離線優先與自動遠端 Fallback**：優先偵測解壓目錄中的 `herdr-mod` 離線安裝；若為單執行檔執行，會自動從 GitHub 下載最新套件完成安裝。
- **Release 打包升級**：發布壓縮檔（`Manapoint-x.y.z-win.zip`）直接內附 `herdr-mod/` 目錄，下載解壓即可離線安裝與使用。
- **文件更新**：於 `README.md` 與 `README-en.md` 完整補充 Herdr Desktop 內嵌版的功能介紹、快捷鍵切換與一鍵安裝指南。

驗證：228 項自動測試全數通過；本機實測右鍵選單安裝流程與 Herdr 佈局切換順暢。Windows 建置與打包由 GitHub Actions 執行。

下載 Windows ZIP 後解壓，執行 Manapoint.exe；launcher.exe 請保留在同一資料夾。已安裝版本可從更新選單升級。
