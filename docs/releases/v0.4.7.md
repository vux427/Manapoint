# Muse Code 用量支援

- 新增 Meta Muse Code：顯示 5 小時與每週的已用百分比及重置倒數。
- 讀取 Muse CLI 既有的 `muse login` 登入，支援 `MUSE_AUTH_PATH` 與 `XDG_CONFIG_HOME`，不要求另填 API key。
- 可在設定頁勾選 Muse Code，沿用現有排序、窗口顯示、用量提醒、歷史、托盤及鍵盤 LCD 資料來源。
- 登入失效或請求太頻繁時保留上次成功數字並顯示原因；沒有有效訂閱、未完成付款或 Meta 未提供用量時顯示說明，不合成 0%。
- 不儲存或輸出 token、推論 key、email 或付款資訊。

使用方式：先執行 `muse login`；若已自訂顯示清單，更新後請到設定頁勾選 Muse Code。Meta 可能在 5 小時窗口閒置時省略整份用量，此時面板會顯示未提供用量的說明。

驗證：202 項自動測試通過。Windows 建置與打包由 GitHub Actions 執行；Muse Code 尚未以真實 Meta 訂閱帳號驗證。

下載 Windows ZIP 後解壓，執行 Manapoint.exe；launcher.exe 請保留在同一資料夾。
