# Antigravity 額度相容修正與 Gemini 分組

- 補強 agy 額度回應解析：支援重新命名的 bucket、模型群組與窗口名稱、巢狀 remaining 比例及不同回應封裝。
- 空的或無法辨識的額度回應不再誤判為「此帳號沒有這組模型的額度」，也不寫入共用快取；會嘗試備用主機，暫時取數失敗時保留上次數字。
- Gemini 共用池與 Gemini 4 Argon 週額度合併在同一張卡分組顯示：共用池 5h／7d 並排，Argon 使用整列長條，避免新增卡片拉長面板。
- 精簡主題將 Argon 放入原本空白的第三格，維持單列；歷史紀錄、用量提醒、耗用預估與鍵盤 LCD 保留各池的獨立資料。
- 略過停用的額度窗口，並避免把 Argon 餘額覆蓋到原本 Gemini 的週額度。

驗證：215 項自動測試通過，並以 Chromium 檢查五種主題、直向／橫向及單／多帳號共 20 種版面組合。Windows 建置與打包由 GitHub Actions 執行；額度解析尚未以使用者帳號的實際 API 回應驗證。

下載 Windows ZIP 後解壓，執行 Manapoint.exe；launcher.exe 請保留在同一資料夾。已安裝版本可從更新選單升級。
