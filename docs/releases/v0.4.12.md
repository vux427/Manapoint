# opencode Console 登入優先與自動切換

- `opencode.db`（`opencode` Console OAuth 登入與 `opencode-go` 金鑰）優先順序調整至舊版 `auth.json` 之前：當 `auth.json` 殘留已過期的舊 API Key 時，自動切換顯示 Console 登入的用量，且舊金鑰不會蓋過 Console 的連線狀態。
- Console OAuth 憑證若在查詢 `/api/config` 或 `/inference/go/v1/usage` 時遇到 401，會自動以 `refresh_token` 換發並重試一次。
- `diagnose.js` 新增 `opencode.db` 各 integration 憑證結構與到期時間的脫敏診斷輸出。

驗證：220 項自動測試通過；以本機真實 `opencode.db` Console 登入搭配過期 `auth.json` 金鑰實測確認。Windows 建置與打包由 GitHub Actions 執行。

下載 Windows ZIP 後解壓，執行 Manapoint.exe；launcher.exe 請保留在同一資料夾。已安裝版本可從更新選單升級。
